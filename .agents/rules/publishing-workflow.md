# Publishing Workflow Rule

For all future website changes in this repository:
1. **Local Changes Only**: Apply modifications only in the local project files.
2. **Local Validation**: Start the local development server (or test locally) and validate all changes.
3. **No Automatic Commits or Pushes**: Never perform `git commit` or `git push` automatically after making edits.
4. **Explicit User Approval**: Wait for the explicit user instruction `"YES, PUBLISH"` (or direct instruction to publish/push).
5. **Publishing**: Only upon receiving explicit approval, stage the changes, commit with a descriptive message, and push to GitHub.
